# Controlled scenario plan

The planned Stage II validation set contains team-owned, scripted tabletop scenarios. It is not a collection of real factory incidents.

The first engineering set stays within one wrong-part incident class. It will contain 40 controlled variants across five evidence conditions:

- Evidence conditions: complete, missing source, stale document, conflicting source, and ambiguous source
- Controls: correct-part cases, including complete and incomplete evidence
- Variants: part identity, tray assignment, event timing, document revision, and evidence completeness

Each case will declare its expected observations, required citations, permitted next action, and whether the system must abstain.

This is an engineering acceptance set, not an estimate of factory incident prevalence or production accuracy.
